# Contributing

Contributions are welcome. By contributing, you agree that your contribution is
licensed under Apache-2.0.

Run `./gradlew check :app:assembleDebug` before opening a pull request. Tests and
fixtures must be synthetic. Never commit raw TrainHeroic exports, programming
text, account identifiers, credentials, tokens, signing material, or screenshots
of personal health data.

Bug reports should attach only the shape-only report generated by SyncHeroic.
Raw JSON is neither needed nor accepted.
